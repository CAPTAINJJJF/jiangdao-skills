# 江导 Skills｜按需求选择

已经知道想做什么，直接选择下面的能力；还不确定从哪一步开始，找对应分身。下表列出的14个基础入口既能单独启动，也能参与分身接力。发布复盘尚待完善，暂留内容编导内部，不列为独立入口。

“独立使用”指可以直接发起任务。安装仍使用完整包，以保留共享规则、脚本和必要依赖；不用先学完或走完三个分身。

## 认识自己与深聊

| 想做什么 | 启动语 | 最少带什么 | 能得到什么 |
|---|---|---|---|
| 认识自己、倾诉、探索内心、每日复盘、提取本人经历 | 启动本我分身；每日复盘 | 一件正在发生的事、困惑或个人材料 | 当前认识、心力支持或有来源的本人素材；按需要沉淀人格库 |
| 准备一次 Chat / Live 深聊 | 启动对话搭子；帮我准备Live深聊大纲 | 一个具体议题和希望聊清的事 | 可复制的深聊大纲；此入口负责编排，实际对话在目标 Chat / Live 中进行 |

对应入口：[本我分身](../jiangdao-self/SKILL.md) `$jiangdao-self`；[江导对话搭子](../jiangdao-dialogue-partner/SKILL.md) `$jiangdao-dialogue-partner`。对话搭子归属本我，也可供其他分身和独立任务调用。

| 想做什么 | 启动语 | 最少带什么 | 能得到什么 |

| 想做什么 | 启动语 | 最少带什么 | 能得到什么 |

| 写口播稿、高保真改写、混合二创或灵魂创作 | 启动内容生产；帮我写口播稿 | 本轮题目与对应模式的原始材料 | 经过资料核验和用户确认的可拍摄逐字稿 |

写稿输入按模式区分：高保真改写需要指定的一篇完整原稿；混合二创需要主来源与独立补充输入；灵魂创作需要本人事件、口述、笔记或原稿及认可的判断。缺少资料时先补本条所需内容，不要求完成整批赛道研究。

## 容易混淆的说法

| 表达或场景 | 选择依据 |
|---|---|
| 每日复盘 | 本人的经历、选择、状态用本我；明确指向已发布视频与数据由内容编导接收；工作完成清单与日程不自动转为本我深聊 |
| 今天做什么 | 现有IP接力计划中的今日任务用7天行动计划；经营优先级尚未明确用操盘手；普通日程安排使用相应日程工具 |
| 不知道讲什么 | 整个账号的人群与主题不清楚用方向探索；已有方向只缺具体选题用选题共创 |
| 写文案 | 视频正文用内容生产；已验收成片的推送语、标签与发布标题用视频发布；普通邮件或其他文稿不自动套用IP流程 |
| 视频剪好了 | 用户明确要求准备发布时用视频发布；只报告进度时更新当前状态，不自动上传 |
| 用ChatCut / 导出剪映 | 剪辑任务用视频剪辑；只转换已有ChatCut时间线用ChatCut转剪映；单说工具名不足以决定操作 |

## 独立启动与接力规则

1. 对目录中已开放的入口，明确指定 `$jiangdao-*`、完整名称或“启动……”时使用对应当前 Skill。发布复盘是当前例外，即使从旧启动语或旧入口点入，也先由内容编导接收并按需调用内部模块。只讨论、整理或修改 Skill 的说明不等于要求执行它。用户明确选择其他工具或方法时按其选择，不抢占。
2. 已开放的单项任务直接进入对应专业能力；需要判断阶段、重审经营方向或组织连续任务时再调用分身。总分身收到具体请求时直接路由，不因没有走过上游而重启全套初访或诊断。
3. 当前任务已有的事实、目标、材料和确认可以代替上游交接卡中的对应信息。只补会影响本次结果的缺口；缺卡片名称不等于缺事实。直接启动仍保留题源资格、生产资料门、真实数据、剪辑确认、发布授权和资料归属边界。
4. 确有前置依赖时，在当前任务读取并调用所需 Skill，带回结果继续原任务；不要求用户另开一轮或自己记住接力指令。只有缺少必要输入、能力不可用或需要用户决定时停在具体缺口，不用旧流程临时代替。
5. 交付当前任务后按用户已授权范围决定是否继续。只要求拆解就停在拆解，只要求找方向就交付方向；可提出相关后续建议，但不自动启动7天计划、写稿、剪辑或上传。正文里的“交回上游”“交给下游”在独立模式下表示保留可接力结果，不扩展任务。
6. 当前项目有归属明确的正式数据库时，按各能力合同保存可追溯增量。单项拆解或发布复盘没有正式库时，先在当前任务交付结果并保留增量；不跨项目找库，也不强制先建整库。选题所需问题池仍按选题合同建立和核验。
7. 同一能力只维护一套规则、一个正式入口。旧称只做兼容映射：“江导战略行动”对应7天行动计划，“灵感创作”对应内容生产中的灵魂创作；不得从备份、归档或旧任务恢复另一套执行协议。正文按当前需要介绍能力，用户无需记忆内部文件名。

## 更明确地启动

自然语言可以调用，也可以用完整启动语减少歧义。Codex 支持时可明确写 `使用 $jiangdao-deconstruct 拆解下面这篇内容`。豆包使用中文完整启动语，并以它实际发现的已安装能力为准。

安装或修改入口后，用新任务核验实际发现与调用；旧任务可能保留启动时的说明。文件、链接和安装检查通过只说明配置可用，不能保证每次自然语言路由都正确。
