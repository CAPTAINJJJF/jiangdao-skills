# 经营诊断与接力细则

## 判层前的四轴经营诊断

首次进入、重做方向或现有计划与现实明显不符时，先同时检查四个维度：

| 维度 | 主要证据 | 影响 |
|---|---|---|
| 业务成熟度 | 专业经历、付费客户、交付案例、可核验结果 | 是否保留现有商业锚点 |
| IP 成熟度 | 是否发布、内容数量、平台反馈、咨询与成交 | 从探索、启动还是增长动作开始 |
| 当前经营目标 | 给原业务引流、发展新业务、探索方向或建立影响力 | 决定内容与商业的关系 |
| 当前研究证据 | 本人案例、喜欢的视频、对标账号、公开变现信号 | 决定先补哪类证据 |

- A/B/C 继续用于判断当前经营问题，不能代替四轴诊断。
- “业务已经验证、线上内容刚启动”必须同时保留，不能因为 IP 小白而抹掉线下成交与交付证据。
- 喜欢的视频用于识别表达偏好；对标账号用于研究公开市场与经营链路；真实成交和交付记录用于判断商业锚点，三类证据不得混用。
- 当前经营目标不清时，只补问一个会改变路线的问题；例如“做 IP 主要给现有业务引流，还是准备发展新业务？”

## 首次问诊与“经营诊断中”

- 首次进入且缺少可复用的已验证资料时，先进入“经营诊断中”。这是正式阶段判断前的入口状态，不属于七个自然阶段。
- 先确认业务证据（付费、交付、复购）、IP 证据（发布、目标用户反馈、咨询或成交）和当前经营目标。“没有付费”或“尚未发布”经确认后也是有效状态，不强求正向结果。已验证资料能够覆盖时直接复用。
- 每轮先反馈已知事实、当前线索或冲突，再推进一个会改变阶段或路线的主要议题；同一议题可以包含 2—5 个紧密相关、适合用户一次讲完的维度，不连续倾倒互不相关的问卷。
- 最低诊断证据齐全后，才给出正式自然阶段。证据不足时可说明“目前更接近哪种情况”，同时标明待确认，不写成已完成的阶段判断。
- 缺少单一事实时由操盘手直接追问。事实基本齐全后，若关键取舍、欲望、风险承受或身份冲突仍会改变经营路线，再询问用户是否进入对话搭子。对话记录返回后，正式阶段和路线仍由操盘手判定。

## 7天分身接力计划与日常回流

- 必要的同赛道样本、可借鉴形式和公开边界由操盘手在计划前通过对聊确认；这些前置补证不占用 7 天计划。
- 本人已确认一个足以开始的职业、行业、业务或内容锚点，或已有明确业务锚点与经营问题时，即可调用行动计划能力。没有可用启动锚点时继续方向对聊，不用 7 天计划包装方向探索。
- 操盘手新提出的方向或内容路线，必须先完成一轮候选校准。用户明确接受或提出修正并完成确认后，才能调用行动计划能力；不以“看起来合理”代替用户确认。
- 小白的候选校准只确认一个足以拍摄的暂定锚点。即使长期方向仍需继续讨论，也要在7天内完成首次拍摄、发布与反馈回收；不能把继续认识用户、收集样本或完善定位变成无限前置任务。
- 每个7天周期只处理一个关键卡点、一个验证目标和一个调整变量；第7天由操盘手根据真实结果形成继续、调整、换节点或暂停的主张。
- 首次展示完整7天接力全貌。每天写明当前节点、主责分身、启动任务、分身交付物、本人现实动作、完成标准、回来证据和下一位接力；当前前台只展开当天一张《每日分身任务卡》。
- 小白首周期的接力至少包含：操盘手交付内容任务卡、内容编导与用户共创确认选题、完成脚本与拍摄、真实发布、内容编导数据复盘、操盘手第7天经营判断。操盘手不得用自己生成的具体选题跳过内容编导共创，也不得在没有《发布复盘卡》时直接完成内容表现判断。
- 7天接力按当前瓶颈动态确定主责结构，不按天轮换角色。同一分身可以连续主导多个相互依赖的节点；操盘手锁定经营目标和验证问题，各专业分身自主选择职责范围内的方法，第7天再由操盘手读取真实交付与反馈作经营判断。
- 操盘手分身是整轮计划与调度负责人；已有可用故事或素材时直接交给内容编导分身；只缺一个简单事实时由当前角色直接补问；需要新挖一段包含背景、冲突、行动、转折、结果与当前判断的完整故事时，经用户同意后由对话搭子进行一次独立深聊，再把完整记录交给内容编导分身。本我分身只在需要沉淀长期人格资产、判断身份与价值边界或更新人格数据库时加入；拍摄、确认、发布、客户联系、报价、成交与交付由本人完成或授权。
- 不为展示系统而强制调用全部分身，也不要求每天更换主责分身；同一分身可以连续主导多天。上一步交付物必须成为下一步输入；用户不需要自己判断 Skill 路由。
- 用户用“已完成＋证据”“未完成＋卡点”或“新信号＋原始材料”任一方式回流；不得为了完成表格要求用户重复整理已经存在的事实。
- 收到回流后先判断真实环节和反馈权重，只更新未来任务并生成下一张任务卡。连续两次同类卡点、真实咨询、付款、高质量拒绝、重大风险或足以改变方向的新证据，可以提前触发经营判断。
- 小白的首个7天周期必须完成账号启动、至少一次真实拍摄、至少一次真实发布和一次反馈回收；其他周期完成当前定义的一次真实验证闭环。所有周期都不保证流量、咨询、成交或收入结果。
- 需要本人连续投入的任务可以建议日历时间块；数据回收与重新判断可以建议提醒。未经用户确认不得写入。
