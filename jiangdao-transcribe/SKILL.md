# 江导视频转写

版本：V1.0.2

## 启动与独立使用

- 启动语：“启动视频转写”；“把这个视频转成文字”。也可明确调用 `$jiangdao-transcribe`。
- 有权访问的音视频链接或本地文件，附已知专名（如有）。按需要输出逐字稿、时间轴或原始字幕，不要求先有账号方向或剪辑计划。
- 独立启动和分身接力的范围遵守 [入口与使用目录](../shared/skill-entry-guide.md#独立启动与接力规则)。

只完成“媒体到可信文本/时间轴”，供剪辑和内容拆解继续使用。

## 执行前读取

完整读取 [transcription-contract.md](references/transcription-contract.md) 和共享的 [内容编导前台文本格式合同](../shared/content-frontstage-format-contract.md)（按合同“读取范围”加载公共规则与第六节）。互联网链接需要取回平台内容时，先读取 [平台操作与发布方式合同](../shared/platform-operation-contract.md)。小红书仅接收第三方 API 或用户人工提供的字幕、媒体等材料；不调用 `agent-reach` 或账号直连补抓。其他允许的平台再同时使用 `agent-reach` 并按平台路线取回媒体；不能把“详情页可见”当成“媒体不可得”。《角色标注逐字稿》的用户可见格式只以共享前台格式合同为真源。

本机 MLX Whisper、字级时间轴和剪后原始 SRT 已收进本 Skill 的 `scripts/`，不依赖云端 ASR 或已淘汰的外部基础剪辑入口。

## 流程

1. 确认媒体来源、访问状态、授权边界和输出形式。
2. 优先读取可信平台字幕；没有可靠字幕时再获取音轨并调用 ASR。
3. 本机媒体运行 `scripts/run-local-asr.sh <媒体> <独立输出目录> [专名表.txt]`。脚本先检查同源缓存，首次运行自动准备 MLX Whisper 环境和模型，后续全程本地处理。
4. 需要剪辑时间轴时，进入输出目录运行 `scripts/generate-word-timeline.js asr_result.json`。
5. 需要当前成片的原始字幕时，运行 `scripts/generate-srt-from-video.sh <成片> <字幕输出目录>`。
6. 保留原始识别 JSON；校正人名、产品名、英文名、行业术语和明显同音错字，不确定处标 `[待核实]`。
7. 研究批次需要内部逐字稿时，运行 `scripts/render-research-transcript.js <asr_result.json> <metadata.json> <输出.md>`，统一写入来源、识别段数、人工听校状态和版权边界。
8. 对生成文本执行自动质量检查并保留失败原因。重复词、循环字符、不可能的文字密度或明显异常文字体系直接标失败；自动检查通过后仍由上游完成语义复核。
9. 当前本地引擎只负责语音识别，不把转写段自动当成声纹身份。多人内容需要额外的本地说话人分离或人工回听，再结合称呼、长句、问答关系和情景切换映射语义角色；证据不足时保持中性标记。
10. 纯画面内容的 ASR 标 `not_required`，返回内容编导改走 OCR 或视觉证据路线。输出逐字稿、时间轴/字幕、转写状态和待核实词后停在上游调度边界，不自行宣称样本合格。

### 抖音媒体路线

1. 公开详情页先用 OpenCLI 复用 Chrome 登录态；从详情页作者链接取得 `sec_uid`。
2. 运行 `scripts/fetch-douyin-media.sh <视频 URL> <临时 MP4> [sec_uid]`。脚本用 `opencli douyin user-videos` 精确匹配作品 ID、立即下载 `play_url`，并以 `ffprobe` 验证格式、字节数和时长。
3. 作者最近 20 条作品没有目标 ID 时，状态写“后备采集待执行”，转入 MediaCrawler 或受维护的浏览器/Cookie 下载器；不得把一次 URL 失效记成平台没有媒体。
4. MP4 验收通过后再运行本机 MLX Whisper。临时媒体和原始 ASR 放在 `/tmp` 或任务临时目录，项目只保存内部逐字稿、来源、处理元数据和证据状态。
5. 详情页需要登录、验证码或设备确认时停止自动尝试，明确请求真人处理。

图文正文可直接读取时不运行 ASR。自动调度完成后只返回调用方，不自行启动拆解或剪辑。

## 降级

- 无法下载：按平台路线刷新媒体地址、尝试可信字幕并执行一次后备采集；仍不可得才报告失败，保留已尝试路线和错误层级。
- ASR 部分成功：保留已识别范围、缺口和失败信息。
- 本地环境缺失：脚本自动准备隔离环境；缺少 `uv`、`ffmpeg` 或 Apple Silicon 条件时明确报告，不静默改用付费云服务。
- 第三方公开素材：完整转写只作内部研究证据，对外交付遵守来源和版权边界。

## 完成标准

- 原始 ASR、整理稿和时间轴可追溯到同一媒体与配置。
- 缓存命中或新运行均有明确记录，同一输入与配置不重复计算。
- 最终稿顺序完整，明显错误已校正或标待核实。
- 自动质量检查与语义复核状态分开记录；ASR 运行成功不能单独作为可信逐字稿结论。
- 多角色使用语义角色，单人内容标“旁白”或真实身份。
- 自动调度停在调用方要求的交付边界，没有静默进入下游。
