# 首次认识

## 目标

第一次先为正式对话建立一张可继续生长的访谈地图。快速采样只负责打开分享欲、了解当前 IP 状态并组织正式对话；完整对话记录返回后，再建立唯一《人格数据库 V0.1》。

首次认识分成两段：先依次用五个初识主问题快速建立基本坐标，再停止当前任务中的零散提问，生成可交给 Chat / Live 执行的正式对话交接稿。目标 ChatGPT 项目已明确安装同版本 `DP-LIVE-V4.1` 时交付短动态卡；协议状态不明或未安装时交付精简完整稿。自然承接用户已经提供的材料；已回答的维度直接跳过或改成针对缺口的追问。

## 内测与录课演示

当前任务处于内测、盲测、录课演示或模拟学员空间时，每个新任务默认从首次认识开始。只读取当前空间里本轮明确指定的学员材料，不自动接入操作者在其他项目中的人格数据库。若新任务带回了由本我深访大纲产生、身份与返回关系可追溯的完整对话记录，则续接该演示学员进入建库阶段。

演示开始时直接进入第一个初识问题，不向镜头前的用户解释后台搜索、历史版本或操作者身份。用户明确要求继续某位演示学员时，才读取当前空间里该学员已保存的演示数据库。

先按主 Skill 判断新老学员与材料归属，不能只凭没有数据库判定初访。确认是新学员后，普通认识任务进入五问快速采样；当下想倾诉或请求情绪疏导时，先按 [情绪疏导与心力恢复](emotional-support.md) 接住开头、确定议题并主动准备 Live 交接。交接中保留初识未完成状态；记录返回后复用已知材料继续初识，不重新问已回答的问题。

## 第一段：五个初识主问题

默认按以下顺序推进，一次只呈现一个问题：

1. **当前 IP 情况**：“你现在有没有在做个人 IP？目前做到哪一步了，是怎么一步步走到今天的？”
2. **当前业务与市场验证**：“你现在主要在哪个平台表达、讲什么？有没有做过内容、产品，收到过用户反馈或付费结果？”
3. **启动原因与目标**：“你为什么想做个人 IP？现阶段最希望通过它解决什么问题、得到什么结果？”
4. **经历与能力证据**：“过去有哪些经历、案例、结果或他人反馈，最能说明你擅长什么、值得被别人认识什么？”
5. **卡点、资源与边界**：“你现在主要卡在哪里？手上有哪些时间、资源和限制？哪些表达方式或经营方式你不愿接受？”

五个信息维度固定，具体措辞可以自然调整：

- 用户的回答已经覆盖某条主线时，记录证据并跳过重复提问；
- 必要事实澄清可以插入，但不因此丢掉尚未完成的初识主线；
- 用户说“不确定”“不知道”或选择跳过时，记录为当前未知，继续下一条；
- 每连续一至两个问题，先镜像复述一项有依据、可纠正的理解，再继续；
- 五个维度都应形成已回答、已覆盖或已跳过状态；用户主动要求停止时除外。

## 第二段：切换到正式对话

五个初识维度全部形成已回答、已覆盖或已跳过状态后，立即停止当前任务中的内容追问。明确告诉用户：“基础认识已经够了，接下来进入正式对话阶段。”

随后调用 `jiangdao-dialogue-partner`，把快速采样整理成一份可复制的本我深访交接稿。短动态卡与精简完整稿都必须包含主题与目标、已确认事实、用户当前判断、关键矛盾、至多一个候选判断、开场、收束条件，以及“完整记录交回 `jiangdao-self`”的结束动作；完整模式额外携带精简固定协议。

出现多个值得深访的主题时，按信息价值和当前相关性排序，一次只交付第一份大纲；其余主题保留为待续线索。用户说“都做”时也按顺序推进，等待第一份完整记录返回后再进入下一主题，不一次倾倒多份长大纲。

默认把交接稿交给 Chat / Live 执行，不在当前任务中继续一问一答。达到停止条件、用户要求暂停或主题自然收束时都可以返回本我，这不构成执行授权；只有用户明确说“进入执行”时才在返回交接中标记执行意图。对话搭子不自动创建任务、计划或正式交付。用户明确要求“就在这里聊”时，可以留在当前任务进入正式对话，但必须先宣布切换，并遵守对话搭子协议：先承接和贡献思考，问题只在确实需要时提出，不让每一轮都以新问题收尾。

正式对话围绕高信号真实经历推进，关注具体现场、选择、判断依据、结果、代价、外部反馈和用户原话。其余未展开线索保留在访谈地图中，不把五条初识主线扩成五套长问卷。

## 最低覆盖

- 当前状态：正在经历和推进什么，处于什么 IP 阶段；
- 当前 IP 与业务状态：表达平台、主题、内容或产品尝试、用户反馈和付费验证；
- 一段具体经历、选择、转折、反馈或卡点；
- 至少一项故事、判断、能力证据、动力、边界或表达特征；
- 材料来源、时间、归属和当前未知；
- AI 对本次材料的提炼；证据足够时可包含一条待验证盲区。

其余经历和资产以后递增补齐。用户想停时不以字段不完整阻止交付。

快速采样不得只问一个宽泛问题便收束。五个维度均形成已回答、已覆盖或已跳过状态后，不再继续零散深挖。正常完成时，应留下已回答、已跳过、当前未知和后续可深挖线索，支持正式对话直接接续。

## 当前 IP 状态

可以记录带日期的状态快照：现在在做什么、已经尝试什么、发生过什么反馈、有哪些现实限制。不得把未来经营方案或 AI 的商业建议写成人格资产。

## 交付

快速采样完成后，先用一句话说明目前看见的核心线索，再按目标 Chat 的协议状态交付可复制的本我深访短动态卡或完整大纲。完整对话记录返回后，AI 建立 V0.1，并用一句话告诉用户“这次先看见了什么”，再说明写入了哪些层级。用户指出偏差时立即修订；不逐条询问是否同意写入。

内测 / 演示模式下，深访大纲和后续 V0.1 都作为隔离的演示结果交付；不得写入操作者的真实人格数据库。用户未明确要求保存时，只在当前对话展示。
