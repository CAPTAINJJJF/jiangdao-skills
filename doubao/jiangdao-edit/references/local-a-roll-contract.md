# 本机 A-roll 路线合约

只在 `route_lock=local_a_roll` 时读取。

本路线是 ChatCut 不可用时的备选，或用户明确指定本机处理时使用。新剪辑任务默认先选 ChatCut，不因口播较短、交付简单或本机脚本可用而直接进入此路线；恢复已确认本机任务时继续原路线。

## 1. 工具链

```text
jiangdao-transcribe/scripts/run-local-asr.sh
jiangdao-transcribe/scripts/generate-word-timeline.js
scripts/detect-en-stutter.js
course-cut-review/scripts/generate-review-page.mjs
jiangdao-transcribe/scripts/generate-srt-from-video.sh
```

工作目录独立于原片目录：

```text
task/
├── manifest.json
├── transcription/
├── analysis/
├── review/
└── delivery/
```

## 2. 首次审核前预删与其他候选

先执行公共合约的“首次审核前的冗余与重复预删”。明确的冗余、重复句与重说必须在首次审核页默认划线，随后再列其余内容取舍候选。

### 低风险自动候选

- 明确的字面重启、短词卡壳和逐字子集重复；
- 英文词头后紧接完整词，如 `ben benchmark`；
- 已确认删除内容内部的空白；
- 超出目标区间的气口，仅压缩超出部分。

其中明确的字面重启、卡壳与重复必须在审核页默认划线，用户始终可以恢复。气口和空白按第 5 节在内容确认后另行处理，不混入首次冗余预删。

### 高风险待确认

- 超出明确冗余与重复范围的整句、长片段或跨句删除；
- 语义相近但覆盖关系、内容功能或新增价值仍不确定的段落；
- 开头相同、后半内容分叉的表达；
- 随机访谈的结构重组、说话人边界和结论；
- 片头片尾未转录区间，尤其包含动作、画面信息或环境声时。

高风险项列出删除段、保留段、内容功能、覆盖理由和删除后的衔接。证据不足时只提示，不默认划线。默认不启动多角色或多 Agent 复核。

## 3. 口误、重复与残句

- 先按语义分句，再判断；不得只逐字扫异常字符。
- 口误、当场纠正、字面重说和残句通常删较早版本、保留后面的完整版本。
- 前段含有后段未覆盖的独有信息时，只删被覆盖部分。
- 句内重复只删前面的重复片段，不删整句。
- 完成字词扫描后，再按播放顺序做一次跨句重说复核。

## 4. 语义重叠

确认满足“同一意思、同一内容功能、无新增价值”时，在首次审核前默认划线删除较弱版本。故事现场与总结、结论与机制、事实与态度、限定与反例承担不同功能，均应保留；无法确认覆盖关系时列为待确认。

选择保留版本时依次看：新增信息、具体画面、自然口语、人物情绪和前后衔接。

## 5. 语气词、气口与头尾

开工时按公共合约询问提前倍速，由用户决定是否加速及倍数。选择加速后，先建立该速度的工作基线，再做后续内容预删与气口整理；不预先渲染覆盖原片。以下气口时长均指用户选定倍速下的最终播放时长，剪辑判断与试听使用同一速度。

- 保留自然的“嗯、就是、然后”；只清理连续、空转或显著拖慢表达的部分。
- 句中换气保留约 0.2—0.4 秒，正常句间约 0.4—0.8 秒，段落或故事转场约 0.8—1.3 秒。
- 内容确认后再整理气口；禁止按统一静音阈值全片批量删除。
- 比较视频时长与首末转写时间，检查 ASR 盲区。头尾内容先看画面与声音，再决定保留、缩短或删除。

## 6. 定稿口播与随机访谈隔离

- `fixed_script` 保持原顺序，以确认稿为语义基准。
- `random_interview` 才允许跨时间段重组。先锁唯一核心观点，再给 1—3 个开头和各自的素材证据。
- 不改变说话人归属、限定词、因果和时间关系，不生成原素材中没有的承接句。

## 7. 审核与渲染

唯一审核入口为 `course-cut-review` 生成的可交互文字剪辑审核页。页面必须支持划线删减、恢复、切段、拖动排序、候选区、自动保存、最终确认和确认方案导出。审核页只记录剪辑意图，不能直接修改或渲染视频。

确认方案导出后，先校验来源、内容顺序、删除区间与用户确认时间，再由当前活动路线的正式渲染器从原片生成新版本。旧版逐词勾选页及其本机直剪服务不得用于新任务。

渲染规则：

- 从原片和确认区间一次渲染，预览代理不参与最终编码；
- 按实际 codec、profile 与 pix_fmt 选择兼容编码器；
- 分卷或长视频可以分批渲染后拼接，必须核对顺序和边界；
- 倍速按开工时用户选择生效一次，视频与音频使用同一时间基准并保持音调；从原片渲染时换算剪点和气口，已加速中间文件不再叠加倍速；
- 输出检查时长、音画、剪点、片头和片尾。

## 8. 字幕

1. 从当前粗剪或外部精修回片重新提取音频并转写。
2. 保存原始 ASR JSON 和 `video.raw.srt`。
3. 对照实际音频、确认稿、专名表和上下文校对。
4. 只修正文、断句、专名和明确误识别，不补入视频中没有的话。
5. 输出同版本 `subtitles.srt` 和无时间码逐字稿。

字幕验收：时间码单调、无空字幕、无连续重复、片尾不越界、专名已核对；用户要求无标点、单行或每行字数时再检查对应格式。
