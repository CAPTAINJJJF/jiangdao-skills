# 内容机制卡词典

机制卡把爆款中可复用的内容推进方式变成生产约束。卡片从完整原作和拆解中生长；没有来源的新卡只能标为“候选”，不能冒充已验证方法。

## 调用规则

1. 拆解每条爆款时，先还原实际推进链；已有机制卡能准确解释时关联并补充来源，无法覆盖时创建候选卡。
2. 选题建议可以自然提到候选机制；用户选中题目后，只推荐一张主机制卡，并把实际推进链和原料条件写入《生产决策卡》。卡片字段与确认方式按 [选题合同](../jiangdao-adapt-topic/references/topic-candidate-contract.md) 和 [前台格式合同](content-frontstage-format-contract.md) 执行。
3. 生产必须按机制卡逐段分配素材；素材不足时删段、补料或换卡，不能用泛化解释把篇幅填满。
4. 初稿完成后检查：火点是否保留、推进是否真实发生、厚度来源是否落到具体材料、常见塌陷是否出现。

## 卡片字段

- `mechanism_id` 与名称；
- 所属框架大类；
- 适用问题与内容任务；
- 中心承诺或主要火点；
- 必需原料；
- 功能推进链；
- 内容厚度来自哪里；
- 开头、能力证明与转化句可出现的位置；
- 常见塌陷；
- 来源样本与证据状态；
- 适用生产模式；
- 更新时间。

## 当前机制卡

### M01 阶段复盘拆解

- 所属大类：实践复盘型。
- 适用：一个重要且刚需的大问题，需要按早期、中期、后期或其他真实阶段讲清。
- 中心火点：同一个问题在不同阶段会变，用户需要的判断与动作也会变。
- 必需原料：真实阶段、每阶段具体问题、当时判断、采取动作、结果或代价。
- 推进链：`提出大问题 → 说明为什么要分阶段 → 早期问题与动作 → 中期变化与调整 → 后期关键判断 → 总体复盘与适用边界`。
- 厚度来源：阶段差异、判断变化、具体动作与代价，不靠增加条目数量。
- 能力证明：嵌在“我当时怎样判断和处理”的段落；转化放在总体复盘之后。
- 常见塌陷：每个阶段只有一句建议；阶段之间没有真实差异；写成通用知识清单。
- 证据状态：已有真实爆款拆解支持，持续补充来源。
- 适用模式：高保真、混合二创、灵魂创作。

### M02 真实行动复盘

- 所属大类：实践复盘型。
- 适用：内容由“我做了什么”推动，价值来自行动后的判断和心得。
- 中心火点：读者想看到行动现场、意外反馈与当事人的判断变化。
- 必需原料：真实行动、起因、关键过程、意外或冲突、结果、本人复盘。
- 推进链：`我做了一件什么事 → 为什么去做 → 过程中发生了什么 → 哪个结果出乎预料 → 我因此改变了什么判断 → 对相似人有什么提醒`。
- 厚度来源：事件细节、关键选择、结果和反思之间的因果关系。
- 能力证明：用具体行动和决策自然证明；结尾只在确有承接时接产品或下一步。
- 常见塌陷：行动被压成背景，正文变成泛泛的三点心得；虚构结果；把个案写成普遍规律。
- 证据状态：已有真实爆款拆解支持，持续补充来源。
- 适用模式：混合二创、灵魂创作；源稿完整时可高保真。

### M03 冲突重解释

- 所属大类：观点立场型、痛点击穿型。
- 适用：目标用户长期用一种常见解释理解问题，但现实结果与它冲突。
- 中心火点：让用户看见“原来的解释为什么解释不了眼前结果”。
- 必需原料：常见解释、具体反常场景、新解释、支持例子或行动后果。
- 推进链：`熟悉场景 → 常见解释 → 摆出解释不了的矛盾 → 给出新原因 → 用案例或因果讲透 → 落到判断或行动`。
- 厚度来源：新旧解释的证据对照与因果链。
- 能力证明：放在新解释如何得出、如何解决问题的过程中。
- 常见塌陷：只写一句反常识金句；为了锋利虚构研究；随后又用大量限定词磨掉判断。
- 证据状态：候选机制，需随来源样本更新。
- 适用模式：高保真、混合二创、灵魂创作。

### M04 具体场景演练

- 所属大类：干货交付型。
- 适用：用户知道原则却不会在真实情境中采取动作。
- 中心火点：把抽象方法放进一个会发生的现场，让用户直接看到怎样判断和处理。
- 必需原料：一个明确目标、连续或互相关联的场景、每个场景的判断依据和具体动作。
- 推进链：`锁定一个现实目标 → 进入第一个场景 → 说明判断与动作 → 场景变化或升级 → 调整动作 → 总结可迁移原则`。
- 厚度来源：场景之间的递进、判断理由和动作后果。
- 能力证明：通过每次判断展示；转化放在用户已经看见方法有效之后。
- 常见塌陷：罗列五个互不相关的小技巧；每个场景只有口号；没有一个中心冲突。
- 证据状态：候选机制，需随来源样本更新。
- 适用模式：混合二创、灵魂创作；原作本身以演练推进时可高保真。

### M05 身份冲突与选择

- 所属大类：痛点击穿型、观点立场型。
- 适用：用户的专业身份、自我期待和现实回报之间出现冲突。
- 中心火点：准确说出“我明明已经做到什么，为什么仍得不到什么”。
- 必需原料：身份期待、具体受挫场景、现实代价、关键解释、可执行选择。
- 推进链：`说出身份期待 → 展示现实落差 → 命名真正冲突 → 解释冲突如何形成 → 给出选择与代价 → 回到用户想成为谁`。
- 厚度来源：身份、利益、情绪和行动后果同时成立。
- 能力证明：用处理同类冲突的方法或案例承载；避免突然自夸。
- 常见塌陷：只做情绪安慰；用宏大价值观替代现实问题；结尾强行成交。
- 证据状态：候选机制，需随来源样本更新。
- 适用模式：高保真、混合二创、灵魂创作。

### M06 决策地图

- 所属大类：干货交付型。
- 适用：用户面对复杂任务，不知道先后顺序和判断条件。
- 中心火点：提供一张可以据此做取舍的路线图。
- 必需原料：明确目标、关键节点、每个节点的判断条件、失败信号和下一步。
- 推进链：`锁定目标 → 找到第一个判断节点 → 按条件分路 → 逐路给动作和风险 → 汇总优先顺序 → 给出下一步`。
- 厚度来源：判断条件、分支后果与真实案例，不靠步骤数量。
- 能力证明：展示如何取舍和排优先级；承接可放在用户识别自己所处分支之后。
- 常见塌陷：把流程写成平均用力的清单；没有判断条件；所有人都得到同一答案。
- 证据状态：候选机制，需随来源样本更新。
- 适用模式：混合二创、灵魂创作；源稿已有完整决策结构时可高保真。
