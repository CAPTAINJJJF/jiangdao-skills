# 内容编导｜选题加工规则

本规则用于把已经有证据的普通问题加工成更值得拍、也更容易被目标用户识别的选题。它位于“锁定题源与核心问题”之后、“生成《选题候选清单》”之前。

加工只处理选题，不提前生成最终标题、钩子或创作者答案，也不靠强行反常识制造爆款感。

## 输入与边界

本规则接收选题合同已经从赛道问题池筛出的完整问题句，只负责把问题加工成候选。

`元素迁移 / 选题具体化 / 损益显化` 是三种底层加工动作。一条候选可以不加工，也可以按需组合；不设置动作数量配额。原问题的核心需求始终保留。

## 总目标

在不改变原问题核心需求的前提下，提高选题的：

- 目标用户代入精度；
- 问题发生范围的清晰度；
- 用户在点开前可感知的价值或代价；
- 内容实际交付题面承诺的可能性。

后台先记录：`原始问题 → 保留的核心需求 → 加工动作 → 新增元素及证据 → 加工后选题`。前台通过“题源原话”和“生成关系”让用户可以审查这一过程。

## 一、先校准，再批量

没有用户亲自判断过的正反样本时，先进入小轮次校准：

1. 每轮只测试一条规则；
2. 每轮只给两条候选；
3. 用户可以选一条、认可两条或全部 Pass，并说明原因；
4. 下一轮只改变一个变量，避免把题材偏好、句式偏好和加工质量混在一起；
5. 某条规则在不同母题上重复成立，且用户同意进入批量生成后，才写入当前项目的校准依据。

外部爆款只能记录为“外部结构样本”。它可以帮助识别关系反差、损益或表达力度，不能自动升级为当前用户的观点和口味结论。

校准过期条件包括：项目、IP、赛道或目标人群发生变化；用户连续否定整批候选；本轮候选只能靠旧模板复现。出现任一情况时回到两条一轮，不继续批量碰运气。

## 二、损益原则

候选排序先看目标客户能否感知损益。损失通常来自：事情继续恶化、管理者越来越难做、关键事实被隐藏、团队开始失控、关系被反噬、时间和机会持续浪费。收益需要落到一个能够交付的判断、处理方法或现实减负。

“要警惕”“存在风险”“影响权威”“推动行动改进”只说明概念，没有说明目标客户会亲自失去什么。损益需要落到人、动作和后果上。

当前管理沟通赛道的校准样本显示，避免正在发生的损失比泛泛的正向收益更容易触发点击。这是当前赛道倾向，不外推为所有赛道的通用定律。

损益显化仍要保留真实性。夸大灾难、无依据地断言因果、为了情绪编造背叛关系，全部作废。

## 三、把母题发展成完整选题

底层加工动作需要通过一条“问题发展路径”长成完整选题。优先尝试：

- **现场处理**：进入目标客户高频遇到的现场，保留“该怎么处理”的开放空间；
- **前兆诊断**：把已经发生的问题往前推，寻找失控前可识别的变化；
- **信号归并**：把若干零散表现收拢为一个更大的自查或诊断问题；
- **关系反差**：抓住付出、培养、信任与最终结果之间的真实落差；
- **损益落地**：把隐性后果落到目标客户会承担的麻烦和代价。

这些路径不设配比，也不要求每批全部出现。每次只在题源、当前任务或用户校准依据能够支撑时使用。

选题的观点浓度允许有两个状态：

- **开放问题**：给出场景、冲突和损益，答案仍由创作者完成；
- **方向性命题**：给出一个等待认领的判断方向，仍允许解释、反驳和修正。

方向性命题属于候选，不代表用户已经持有这个观点。强结论来自外部爆款或 AI 推演时，后台必须保留来源状态；用户没有认领前不能进入正式内容答案。

## 四、五道质量闸门

每条候选依次检查：

1. **目标客户愿意看**：点开的人就是当前内容希望吸引的人；主要让非目标人群通过批评目标客户获得情绪满足时，属于错受众风险。
2. **损益可感知**：目标客户知道这件事为什么值得现在看，泛化危险词不能通过。
3. **能够撑起完整内容**：题目可以自然展开多个信号、原因、判断或处理动作。只能充当一个分论点的小现象退回素材层。
4. **共鸣范围足够**：具体条件来自高频现场，目标客户容易把自己代入。稀有剧情即使真实，也不自动成为好选题。
5. **确实长出新问题**：候选相对母题改变了时间位置、诊断层级、关系冲突、处理环境或目标客户损益。近义改写直接淘汰。

最后做一次口语检查：目标客户读一遍，能否立即知道发生在谁身上、出了什么事、为什么跟自己有关。连续堆叠抽象名词时，改写成人、动作和后果。

## 五、元素迁移

### 定义

保留原问题的核心结构，只替换一个关键元素，使问题进入另一个人群、对象、阶段、场景或行业。

可迁移元素：

- **人群**：大众问题进入一类具体人群，例如专业人士、内向者、已有团队的老板；
- **对象**：同一种机制换到另一个真实作用对象；
- **阶段**：进入起步、增长、变现或其他有实质差异的发展阶段；
- **场景**：进入开会、直播、初次见客户等具体现场；
- **行业**：借用另一个赛道的问题结构，在当前赛道寻找真实对应问题。

行业迁移借的是问题结构。例如“同样条件下，为什么两类人的结果差异很大”，可以从教育赛道迁移到 IP 赛道；原行业的事实、用户需求和作者答案不随结构迁移。

### 通过条件

1. 原问题的核心需求仍然成立；
2. 新人群、对象、阶段、场景或行业确实存在该问题；
3. 新版本能让一类目标用户更容易产生“这说的是我”的感觉；
4. 新元素在原问题语义和当前任务边界内真实成立，不借用原作者或第三方的身份、经历与成绩。

机械替换、只换名词、只换年龄数字，或新对象身上并不存在该问题时，作废。相邻赛道只能提供可迁移结构；当前赛道证据负责证明新问题成立。

## 六、选题具体化

### 定义

把宽泛、抽象、范围过大的问题，压缩到更具体的人、时间、场景、阶段或限制条件中。目标用户看到后，应能判断问题发生在什么环境里，以及是否与自己有关。

常用动作：

- **具体人群**：例如三年级孩子、不爱看书的孩子；
- **具体时间**：例如中考最后 100 天、考前一周；
- **具体场景**：例如第一次见客户、直播现场；
- **具体阶段**：例如账号前 30 条、第一次爆款后、连续 20 条低流量时；
- **增加限制条件**：例如没有团队、每天只有一小时、只有一台手机；
- **加入时代背景**：时代只作为影响决策环境的具体条件，不单独建立新加工规则。

### 通过条件

1. 限制条件真实存在；
2. 加入后问题范围与用户决策环境更明确；
3. 目标用户能够立即判断与自己是否相关；
4. 内容有足够材料回答缩小后的问题。

随意添加年龄、年份、数字或时间标签，且不改变问题和决策环境时，属于假具体。具体化追求代入精度，不追求把题目写长。

具体条件还要检查覆盖面。“上级恰好在场”“平时最支持的人突然反对”等条件可能改变判断，却容易把完整选题缩成少数人才遇到的剧情。此类条件更适合作为正文中的信号或案例；除非当前目标人群高频遇到，否则不单独成题。

## 七、损益显化

损益显化包括收益显化和损失显化。它帮助用户在点开之前判断：看完能完成什么任务，继续忽略或做错又可能付出什么代价。

### 收益显化

把内容能够真实交付的结果放到选题表面。常见收益包括：

- 省时间；
- 少试错；
- 帮筛选；
- 帮判断；
- 给地图；
- 给清单、模板或方法；
- 压缩大量信息。

收益必须是围绕当前问题能够真实交付的结果。候选阶段可以显示交付类型；方向性判断仍处于待认领状态，尚未确定的数量、结果和方法不写成已经承诺的标题。

“播放量暴涨十倍”“一个方法年入百万”等无法交付的结果不得使用。

### 损失显化

把用户继续忽略、做错或拖延这个问题时可能承担的真实代价放到选题表面。常见损失包括：

- 浪费时间；
- 浪费钱；
- 错失机会；
- 结果继续恶化；
- 长期积累的隐性代价。

损失需要真实因果、明确适用条件和可解释的后果。不得把普通问题包装成灾难，也不得用泛化淘汰焦虑代替证据。

### 通过条件

1. 损失或收益能够从原问题及其适用条件中成立；
2. 它确实会改变目标用户的判断或行动；
3. 内容能够解释因果或交付承诺；
4. 题面没有提前冒充创作者已确认的答案。

## 八、执行顺序

拿到一个合格普通问题后依次处理：

1. **锁定目标客户损益**：先回答目标客户为什么会在意，损益无法成立时不靠句式补救；
2. **选择问题发展路径**：现场处理、前兆诊断、信号归并、关系反差或损益落地；
3. **按需使用底层动作**：元素迁移、选题具体化和损益显化；
4. **通过五道质量闸门**：目标受众、损益、内容承载力、共鸣范围和实质差异；
5. **检查观点状态与口语表达**：标记开放问题或方向性命题，去掉概念堆叠。

任何一步加入假条件、偏离核心问题、吸引错受众或超出内容交付能力时，退回上一步。最终合格数量不足时停止，不用信号素材和近义改写凑数。

## 九、最终检查

每条加工后的候选必须回答：

1. 原问题的核心需求保留了什么；
2. 新增元素为什么在原问题语义和当前任务边界内成立；
3. 加工后目标用户是否更容易代入；
4. 谁会最想点击，是否就是当前目标客户；
5. 损益落到了什么具体后果；
6. 题目能否撑起一条完整内容，还是只能充当一个信号；
7. 具体条件是否覆盖足够多的目标客户；
8. 题目属于开放问题还是待认领的方向性命题；
9. 内容能否真实交付题面承诺；
10. 与题源和其他候选是否存在实质差异。

最简记忆：`先校准 → 找损益 → 长成完整问题 → 过受众与共鸣闸门`。所有加工建立在真实问题上，不为爆款感凭空造概念。
