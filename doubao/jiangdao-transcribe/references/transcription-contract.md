# 视频转写合约

## 输入

- 样本或任务 ID、原始链接或本地媒体绝对路径；
- 来源与授权状态；
- 可选的人名、术语表和已知角色；
- 是否需要字级时间轴、SRT、语义角色和纯文本版本。

## 本地运行与缓存

- 平台已有可信字幕时优先使用，不重复调用 ASR。
- 本机缓存键由源文件路径、设备/文件标识、大小、修改时间、模型和专名提示摘要组成。
- 输出目录已有匹配的 `asr_result.json` 与 `jiangdao_asr_input.json` 时直接复用，并记录 `cache_hit=true`。
- 源文件、模型或专名提示变化后才重新计算；旧结果不覆盖，使用新的独立输出目录或先显式归档。
- 媒体直接在本机解码与识别，不上传音视频。最终剪辑始终使用原片。

## 本机引擎

- 入口脚本：`scripts/run-local-asr.sh`；引擎：MLX Whisper `large-v3-turbo-q4`。
- 运行条件：Apple Silicon Mac、`uv`、`ffmpeg` 和 `ffprobe`。
- 首次运行在 `~/.cache/jiangdao-asr/venv` 准备隔离环境，并下载模型到本机缓存；后续离线复用。
- 可用 `JIANGDAO_ASR_PYTHON` 指定已有 Python 环境，`JIANGDAO_ASR_MODEL_PATH` 指定本地模型目录，`JIANGDAO_ASR_CACHE_DIR` 改变运行缓存位置。
- 可把专名表作为第三个参数传入，或通过 `JIANGDAO_ASR_INITIAL_PROMPT` 补充提示。专名校正需结合上下文，禁止用无边界的全局替换污染正文。

## 处理记录

保存媒体来源、缓存键、时长、ASR 引擎、模型、本地耗时、识别段数、过滤段、缓存命中与失败信息。

互联网平台还要保存：标准内容 ID、媒体地址取得方式、下载时点、下载字节数、`ffprobe` 时长与格式。带时效签名的媒体地址只在临时处理记录中使用，不写入长期交付文档。

## 内容完整性门槛

- 详情页、标题、首屏、评论和平台章节摘要都不能替代完整正文或独立逐字稿。
- 口播与语音主导视频完成内容级拆解前，至少需要可信平台字幕或经过媒体验收、自动质量检查和语义复核的独立 ASR。
- ASR 结果为空、只覆盖片段、与媒体时长明显不符、重复词/循环字符异常，或读完无法可靠理解原内容时标“部分成功”或“失败”，并阻止上游把样本计入合格拆解数量。
- ASR 自动检查只负责发现确定性异常，不能证明文本语义正确。诗词、专名、多角色问答和现场互动必须继续核验文本能否还原实际内容。
- 纯画面视频的 ASR 状态写 `not_required`；异常识别结果保留在处理记录中，不渲染成正式逐字稿，由内容编导改走完整 OCR、逐镜记录或视觉证据路线。
- 第三方公开内容允许保存内部研究逐字稿；面向外部的输出只引用必要短句并保留来源。

## 输出

1. 转写状态：成功 / 部分成功 / 失败 / 待人工复核 / 不适用（纯画面内容）；
2. `asr_result.json` 统一结果；
3. `mlx_whisper_raw.json` 引擎原始结果与 `local_asr_meta.json` 运行元数据；
4. `jiangdao_asr_input.json` 输入与缓存元数据；
5. 可选 `subtitles_words.json` 字级时间轴；
6. 可选 `video.raw.srt` 原始字幕；
7. `transcript.raw.txt`、`transcript.timestamped.txt`、`transcript.raw.srt`，以及按需整理的角色清单和待核实词。

## 字级时间轴

- 兼容顶层 `utterances` 与 `result.utterances`。
- 丢弃空文本、负时间戳等无效 token，并记录数量。
- 时间轴只描述 ASR 实际识别结果；片头片尾未转录区间交给剪辑验收查看声音和画面。
- `subtitles_words.json` 可供确定性卡壳检测和本地审核页使用，不能单独证明删除正确。

## 字幕

- 剪后字幕必须从当前成片重新转写，不能把原片字幕通过删减时间映射当作最终字幕。
- 原始 SRT 保留 ASR 时间码；AI 只修正文、断句、专名和明确误识别。
- 不添加当前视频中没有说出的字句。

## 语义角色

- MLX Whisper 本身不做声纹识别或说话人分离，`local_asr_meta.json` 默认记录 `speaker_diarization=not_run`；
- 单人内容直接标“旁白”或真实身份；多人内容先运行独立的本地说话人分离或人工回听；
- 长句和稳定问答优先于短回应；
- 结合称呼、主客关系、叙事位置和情景切换；
- 声纹编号跨文件或切段可能漂移，不直接等同真人身份；
- 无证据时使用“角色待复核”。

## 版权边界

自有或已授权素材可交付完整逐字稿。第三方公开内容的完整转写作为内部研究证据保存；向外提供时遵守来源、引用和不可替代原作边界。
