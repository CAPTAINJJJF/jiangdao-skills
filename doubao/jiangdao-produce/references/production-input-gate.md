# 单条内容生产资料门

本合同只判断“一条已经选中的内容能不能进入逐字稿生产”。赛道采集批次的 20/10 条目标继续用于建立或更新赛道数据库、形成跨样本判断，不再作为每条内容开稿的统一数量门槛。

## 两种资料资格

- **正式市场样本**：达到当前点赞、全文、来源和证据门槛，可以进入正式拆解、赛道数据库和跨样本市场判断。
- **生产材料**：与当前选题直接相关，内容完整且来源可追溯，可以服务这一条稿件。没有达到正式市场样本门槛时，只能作为生产材料，不能被描述成爆款证明、赛道规律或市场验证。

标题、首屏、索引、平台摘要和二手复述只能提供线索，不能作为主生产材料。

## 三种模式的最低资料包

### 高保真改写

同时满足：

1. 用户明确指定高保真改写；
2. 至少一篇被指定的完整原稿；
3. 原稿来源可追溯并与当前任务相关；
4. 需要删除或改写的第三方身份、成绩、商业与风险内容已经识别。

不要求达到赛道采集批次目标，也不要求先生成《生产决策卡》。原稿缺失到无法还原时返回 `HIGH_FIDELITY_SOURCE_INCOMPLETE`。

### 混合二创

同时满足：

1. 选题已经选中，《生产决策卡》已经确认；
2. 至少一篇完整、可追溯、与选题相关的主来源；
3. 至少一个独立补充输入，可以是第二篇完整来源，也可以是用户已经确认的本人观点、案例、方法、经历或原始稿；
4. 主来源与补充输入承担不同功能，例如问题、场景、论据、方法、边界或本人判断。

只有一篇外部来源、同时没有用户确认的补充材料时返回 `MIXED_INPUT_INSUFFICIENT`。不为了凑数量调用无关材料。

### 灵魂创作

同时满足：

1. 选题已经选中，《生产决策卡》已经确认；
2. 用户原始内容中至少有一个具体事件或真实问题；
3. 用户已经确认一个本条内容要表达的核心判断；
4. 原始内容保留口述、对话、笔记、原始稿或真实事件的来源索引。

市场样本用于校准问题、传播机制和表达选择，可以复用历史资料，也可以在需要时补充。当前没有可用市场样本时，仍可先完成本人内容整理稿，但后台必须标记 `market_calibration_status: unavailable`，不得声称题目或表达已经通过市场验证。用户本人还没有产生核心内容时返回 `SOUL_CORE_MISSING`。

## 单篇题源共创被选中以后

单篇题源候选被用户选中，只代表题目方向成立。进入生产时重新按模式判断：

- 选择高保真改写：使用该篇完整原稿直接进入；
- 选择混合二创：补一份独立来源或用户确认的本人材料；
- 选择灵魂创作：通过口述、对话、笔记或原始稿补出具体起点和核心判断。

不再要求为这一条内容先凑满整个采集批次。

## 后台记录与校验

标准生产任务先按模式预检材料；材料齐备后形成并确认《生产决策卡》。每次开稿前再保存 `生产资料审计.json`，进行最终校验。高保真快速通道直接在审计中记录用户明确指令，不需要前台卡片。

审计文件至少包含：

```json
{
  "schema_version": "production-input-gate-v1",
  "production_mode": "mixed_creation",
  "topic_confirmed": true,
  "production_decision_confirmed": true,
  "high_fidelity_instruction_explicit": false,
  "target_source_id": null,
  "market_calibration_status": "available",
  "sources": [
    {
      "id": "S001",
      "kind": "external_source",
      "full_text": true,
      "traceable": true,
      "relevant": true,
      "function": "问题与场景"
    }
  ],
  "user_original_content": {
    "present": true,
    "concrete_start": true,
    "confirmed_judgment": true,
    "source_ref": "用户口述记录.md"
  }
}
```

运行：

```bash
python scripts/validate-production-input.py <生产资料审计.json>
```

只有输出 `PRODUCTION_INPUT_OK` 才能进入新逐字稿生产。这个校验只判断资料资格，不代替选题确认、事实核验、公开边界与最终人工确认。
