# 江导定位与最小产品

版本：V1.0.2

## 启动与独立使用

- 启动语：“启动定位与最小产品”；“帮我设计最小产品”。也可明确调用 `$jiangdao-position`。
- 现有方向、想服务的人或一个明确产品意图，加已有产品或需求材料。本人请求设计产品可以作为意图，不能当成市场需求证据。
- 独立启动和分身接力的范围遵守 [入口与使用目录](../shared/skill-entry-guide.md#独立启动与接力规则)。

定位回答：为哪类人解决什么问题、用什么性质的产品或服务、如何收费和承接。本模块只承接 B1－产品形成与 B2，目标是形成足以进行首次真实成交测试的最小产品。

## 执行前读取

完整读取 [position-contract.md](references/position-contract.md)。

## B 类子状态

- **B1－账号启动（不在本模块处理）：**已有本人确认的启动锚点，尚无明确问题、需求信号或产品意图。交回操盘手组织 7 天真实表达与反馈验证，不生成产品卡。
- **B1－产品形成：**群体与主题已选，已有明确问题、需求信号或产品意图，没有可测试的最小产品。本人明确请求设计产品可作为产品意图，不能当作需求或成交证据。
- **B2：**已有产品名称、大纲、课件、服务方案或报价，但尚无真实成交。

只要没有“产品体系＋真实成交”，不得判 C。产品设计完整不等于定位已经被市场接受。

## 流程

1. 读取方向卡、个人资产、市场研究、内容反馈、咨询与历史产品资料。
2. 先核对操盘手已确认的阶段与当前意图。直接调用时，若只有启动锚点且无明确问题、需求信号或产品意图，交回操盘手的账号启动验证；没有可用锚点时交回操盘手判断方向探索，不由本 Skill 自行判 A。
3. 进入产品分支时，复用已确认群体与主题；缺少会改变产品判断的事实时只补该缺口或交回操盘手，不以精细定位阻塞账号启动。确认 B1－产品形成或 B2。B2 不重复扩写产品，优先指出首次成交前的关键缺口。
4. 明确目标人群当前要解决的问题、希望获得的结果、为什么可能信任本人，以及不适合服务的人。
5. 形成最小产品：服务性质、核心结果、范围、交付方式、周期、责任边界、价格假设和适配条件。
6. 检查“自己尚未做成却准备直接教别人”的可信矛盾。适用时先让本人把自己当第一个用户，完成最小实践并保留过程证据。
7. 研究现有产品与变现形式只用于形成假设，不机械复制同行课程、陪跑、咨询或价格。
8. 若当前瓶颈是产品形态、交付强度、产品阶梯或开发链路，先确认可选内测扩展 `jiangdao-product` 已安装且允许使用，再交接最小产品卡；扩展缺失时报告具体缺口，不模拟其方法或强行推进重开发；若形态已足以测试，直接提出最快成交路径并交给 `jiangdao-action`。
9. 输出《IP 定位与最小产品卡 V0.x》，后台状态设为 B1－产品形成 / 最小产品草案或 B2 待成交，并只保留一个明确下游。

## 前台交付

- B1－产品形成时直接说“你现在处在最小产品形成期”；账号启动用户交回操盘手，不输出定位与产品卡。
- B2 时直接说“你现在处在首次成交验证期”。
- 不向用户展示 B1/B2 字母代码；只说明当前缺少什么、这轮要完成什么，以及真实付款后将进入首次交付验证期。

## 人类闸门

本人最终确认产品承诺、服务范围、价格、公开表达和是否开始成交测试。没有确认时不联系客户、报价或承诺交付。

## 完成标准

- 后台明确 B1－产品形成 / B2 及依据；账号启动分支已交回操盘手，前台只展示自然阶段名称。
- 定位同时回答目标人群、问题、结果、产品性质、价格与承接方式。
- 最小产品足以测试，不扩成复杂产品矩阵。
- 有产品未成交时保持 B2，没有写成 C 或“定位成立”。
- 明确交给产品配置或行动 Skill 的唯一下一步及需要验证的关键假设。
